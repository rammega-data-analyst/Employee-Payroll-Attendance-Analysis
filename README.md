# Employee Payroll & Attendance Analysis

## Project Overview
This Excel-based data analytics project focuses on analyzing employee payroll and attendance data to understand workforce attendance patterns and salary distribution.

## Project Objectives
- Analyze employee attendance performance.
- Evaluate gross salary and net pay.
- Identify key payroll and attendance insights.
- Present important business metrics through an interactive Excel dashboard.
## Project Files

- Employee_Payroll_Attendance_Analysis.xlsx – Original employee payroll and attendance dataset.

## Tools Used
- Microsoft Excel
## Excel Techniques Used


- Excel Formulas & Functions
- Sorting and Filtering
- Pivot Tables
- Pivot Charts
- Attendance Percentage Calculation
- Gross Salary & Net Pay Analysis
- KPI Calculation
- Data Visualization
- Interactive Dashboard Creation

## Key Performance Indicators (KPIs)

| KPI | Result |
|---|---:|
| Average Attendance | 94.37% |
| Total Gross Salary | ₹3,09,07,150.92 |
| Total Net Pay | ₹2,56,65,520.92 |

## Key Insights
- Analyzed overall employee attendance performance.
- Evaluated total gross salary and net pay.
- Converted payroll data into meaningful KPIs.
- Presented insights using an Excel dashboard.
