# Employee Payroll & Attendance Analysis

## Project Overview
This Excel-based data analytics project focuses on analyzing employee payroll and attendance data to understand workforce attendance patterns and salary distribution.

## Project Objectives
- Analyze employee attendance performance.
- Evaluate gross salary and net pay.
- Identify key payroll and attendance insights.
- Present important business metrics through an interactive Excel dashboard.

## Tools Used
- Microsoft Excel
- Data Cleaning
- Excel Formulas
- Pivot Tables
- Charts & Data Visualization
- KPI Reporting

## Key Performance Indicators (KPIs)

| KPI | Result |
|---|---:|
| Average Attendance | 94.37% |
| Total Gross Salary | ₹3,09,07,150.92 |
| Total Net Pay | ₹2,56,65,520.92 |
